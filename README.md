## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ankush454575-sketch/let-slegalapp-.git
   cd let-slegalapp-
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
   or, if using another stack, install the required packages for your project.
3. Run the app:
   ```bash
   npm run dev
   ```
